# Pointless

Logická hra na trojuholníkovej doske. Z ponuky troch dielikov ukladáš útvary z malých trojuholníkov a vypĺňaš línie v troch smeroch: vodorovne a po oboch diagonálach. Plná línia zmizne a dá body; viac línií naraz a čistenia za sebou dajú viac. Hra nemá časový limit a končí, keď sa žiadny dielik nedá položiť.

Je určená pre mobil na výšku. Zatiaľ obsahuje režim Arcade.

## Spustenie

Potrebuješ Unity 6000.3.26f1 s modulom Android.

1. Otvor priečinok projektu v Unity.
2. Otvor scénu `Assets/Game/Game.unity` a stlač Play.

Android balík: menu **Pointless > Build Android**, výstup `Builds/Pointless.apk`.
